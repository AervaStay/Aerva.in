What runs on its own

Nothing here needs a person. This is what the platform does by itself, and when — so that when a badge or a review moves, you can tell whether it was a job or a bug.

Daily review sweep — 02:00 UTC (07:30 IST), every day
Two things. Publishes reviews that are due: both sides in, or 15 days past checkout, whichever comes first — neither party ever reads the other's review before writing their own. Then prompts guests who have checked out and not yet reviewed, once each, never repeatedly.
Quarterly standing review — 1 Jan, 1 Apr, 1 Jul, 1 Oct
Runs inside that same daily sweep, but only on those four days. Re-rates every host, guest and property against a rolling twelve months. Gains are immediate; a loss is capped at one rung per review, so a fall takes as long as the climb did. Badges do not move between these days.
Admin corrections — within 48 hours
The one exception to the above. When you revert a review, the last quarterly review is re-run for just the affected property, host or guest, with that review left out. Nobody else's badge moves. Picked up by the next daily sweep.
Currency refresh — 00:00 UTC, every day
Refreshes the exchange rates used to display prices in a guest's own currency. Cron-only: it cannot be run from this page.

Run the sweep now

For when you do not want to wait for tonight. Safe to run repeatedly: it only ever publishes what is already due and prompts a guest once, so running it twice in a row does nothing the second time.

The second button also re-rates every host, guest and property immediately, instead of waiting for the next quarterly date. Use it after a deploy, or when you need a badge visible today — not as a routine.

Run a Compliance Check

Scans every approved listing for one requirement, flagging any that don't currently meet it with a 14-day deadline to fix it. Safe to run repeatedly — a listing already flagged and still unresolved never gets a duplicate flag.

Currently Open Flags

Every listing with an outstanding, unresolved requirement — clears automatically once the host fixes it and saves. Auto-Blocked means the deadline already passed and the listing was taken off guests' search results until it's fixed.
